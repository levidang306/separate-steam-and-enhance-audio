# IMPORTANT — Quality Gate Must Measure Improvement, Not Only Damage

The verification layer must eventually distinguish between:

```textsafe
```

and:

```textactually improved
```

Do not optimize the system toward "minimum difference from input".

A restoration that makes a severely damaged file only slightly different is not necessarily successful.

Therefore introduce two classes of metrics:

### Preservation metrics

Measure:

```texttiming preservation
transient preservation
band preservation
stereo preservation
```

### Restoration metrics

Measure:

```noise reduction
hiss reduction
bandwidth recovery
harmonic restoration
artifact reduction
clarity improvement
```

The final score should balance both.

Conceptually:

```textquality_score =
    restoration_gain
    - artifact_penalty
    - preservation_penalty
```

The exact formula should be determined from benchmark results rather than arbitrarily fixed.

# Final Engineering Principle

The goal is NOT to make the pipeline perform more processing.

The goal is to make the pipeline **know when not to process**.

The ideal V3 architecture is therefore:

```text
                  ┌─────────────────────┐
                  │       INPUT         │
                  └──────────┬──────────┘
                             ↓
                  ┌─────────────────────┐
                  │     ANALYSIS        │
                  └──────────┬──────────┘
                             ↓
                  ┌─────────────────────┐
                  │ DAMAGE DETECTION    │
                  └──────────┬──────────┘
                             ↓
              ┌──────────────┼──────────────┐
              ↓              ↓              ↓
          TEMPO GATE     DENOISE GATE   BANDWIDTH GATE
              ↓              ↓              ↓
           optional        optional        optional
              └──────────────┼──────────────┘
                             ↓
                  ┌─────────────────────┐
                  │   CONFIDENCE +      │
                  │   DAMAGE MASK       │
                  └──────────┬──────────┘
                             ↓
                  ┌─────────────────────┐
                  │   WET / DRY BLEND   │
                  └──────────┬──────────┘
                             ↓
                  ┌─────────────────────┐
                  │ QUALITY VERIFICATION│
                  └──────────┬──────────┘
                             ↓
                    ┌────────┴────────┐
                    ↓                 ↓
                 ACCEPT             REJECT
                    ↓                 ↓
                  OUTPUT            DRY
```

The final system should be **conservative by default, aggressive only when evidence supports it, and automatically reversible when processing makes the signal worse.**

Do not stop at "the tests pass".

The final goal is:

> **The restored output should be objectively safer, perceptually better, and measurably more faithful to the intended original than the current V2+V3 output.**
